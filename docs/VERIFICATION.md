# Проверка версии SQLite — Кинотеатр им. Павлюка

Дата актуализации: 10.11.2026. Windows, .NET SDK 8.0.427, ASP.NET Core / EF Core 8, настоящий файл SQLite. База сервера MySQL не использовалась.

Debug и Release: сборки успешны, 0 ошибок и 0 предупреждений. При старте на пустом файле автоматически применена миграция InitialSqlite и созданы начальные данные. Повторный запуск не дублирует каталог.

HTTP-проверки выполнялись с настоящими cookie Identity и AntiForgery-токенами. Состояние проверялось отдельным подключением node:sqlite. Все 20 сценариев прошли:

- [x] Публичные страницы и локальные ресурсы отвечают 200.
- [x] Создание SQLite и применение миграции без ручной настройки.
- [x] Новое название, семь баннеров, отсутствие рекламы мессенджера.
- [x] Все 28 оригинальных обложек обновляются в существующем каталоге; файлы присутствуют, обложки не повторяются.
- [x] Регистрация и открытие личного кабинета.
- [x] Выход и повторный вход.
- [x] Защита CSRF и запрет админки посетителю.
- [x] Несколько мест в заказе и сумма с серверной ценой.
- [x] Запрет доступа к чужому заказу и билету.
- [x] Учебная оплата, повторное подтверждение без второго платежа, электронные билеты.

Проверка срока выполнялась сдвигом ExpiresAtUtc только в отдельной тестовой базе. Гонка выполнялась параллельными HTTP-запросами с разными аккаунтами.

В браузере проверены новый логотип и первый баннер, загрузка изображений, мобильное меню и отсутствие переполнения на ширинах 1440 и 390. Сделаны актуальные снимки главной страницы.

Приложение запускалось локально на http://localhost:5157; GET главной страницы вернул 200. Для повторения интеграционного прогона — tests/README.md.
