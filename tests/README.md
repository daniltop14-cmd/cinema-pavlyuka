# Проверка SQLite-версии

Для обычного запуска достаточно Visual Studio / .NET 8. Для этого дополнительного прогона нужен Node.js 24+ с модулем node:sqlite.

Из папки Cinema.csproj:

```powershell
dotnet build
node tests/integration.cjs
```

Сценарий сам создаёт отдельную временную папку и SQLite-файл cinema_test.db, запускает приложение с этой базой и одноразовым случайным администратором. Рабочая App_Data/cinema.db не используется. Миграция и наполнение проверяются без внешнего сервера базы и ручных SQL-команд.

Проверки выполняются HTTP-запросами с cookie Identity и AntiForgery-токенами; результат проверяется независимым подключением SQLite. Гонка — два параллельных запроса от разных пользователей. Срок брони сдвигается только в тестовой базе.

HTTP-порт по умолчанию 5159. CINEMA_TEST_HTTP_PORT меняет порт; CINEMA_TEST_DOTNET задаёт полный путь к dotnet, если он не в PATH. После прогона сервер останавливается. Одноразовые тестовые данные остаются во временной папке системы; пароли в отчёт не записываются.
