# Создаёт таблицы и связи базы SQLite

Здесь лежат миграция SQLite и снимок модели EF Core. Приложение применяет миграции при запуске; файлы миграций создаются инструментом `dotnet ef`.

`20261105184218_InitialSqlite.cs` создаёт 20 таблиц:

| Группа | Таблицы | Для чего нужны |
|---|---|---|
| Аккаунты и роли | `AspNetUsers`, `AspNetRoles`, `AspNetUserRoles`, `AspNetUserClaims`, `AspNetRoleClaims`, `AspNetUserLogins`, `AspNetUserTokens` | Вход, хеши паролей, роли и служебные данные ASP.NET Identity. |
| Афиша и залы | `Movies`, `Halls`, `Seats`, `Sessions` | Фильмы, конкретные кресла и показы с временем и ценой. |
| Заказы | `Bookings`, `BookingSeats`, `Payments` | Владелец и статус заказа, выбранные места, подтверждение оплаты и возврата. |
| Содержимое сайта | `Reviews`, `Services`, `FaqItems`, `ContactMessages`, `SiteSettings`, `TeamMembers` | Отзывы, услуги, вопросы, обращения, баннеры и команда. |

Внешние ключи связывают сеанс с фильмом и залом, кресло с залом, заказ с пользователем и сеансом, а место в заказе — с заказом и креслом. Индекс `IX_BookingSeats_SessionId_SeatId_Active` помогает не допустить одновременной продажи одного активного места. `Up` создаёт таблицы и индексы; `Down` удаляет их при откате миграции. Начальные строки в таблицы добавляет `SeedData.cs` после применения схемы.
